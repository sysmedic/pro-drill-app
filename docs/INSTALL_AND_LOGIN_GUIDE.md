# 📲 ProDrill 앱 설치 & 로그인 시작하기 가이드

모바일 기기 바탕화면에 ProDrill 앱을 설치(PWA)하고 로그인하여 클라우드 백업을 시작하는 가이드입니다.

---

## 📲 1. 모바일 기기별 앱 설치 (홈 화면에 추가) 방법

### 🍎 iPhone / iPad (iOS Safari 기준)
1. **Safari 브라우저**에서 ProDrill 접속 주소를 입력합니다.
   - **주소**: [https://drilling-chart-psi.vercel.app](https://drilling-chart-psi.vercel.app)
2. 브라우저 화면 하단 중앙의 **공유 아이콘**(`[↑]` 모양)을 터치합니다.
3. 아래로 스크롤하여 **`[홈 화면에 추가]`** 항목을 터치합니다.
4. 우측 상단 **`[추가]`** 버튼을 누르면 바탕화면에 **ProDrill 앱 아이콘**이 생성됩니다.

---

### 🤖 Android (삼성 인터넷 / 크롬 기준)
1. **크롬(Chrome)** 또는 **삼성 인터넷 브라우저**에서 ProDrill 주소에 접속합니다.
   - **주소**: [https://drilling-chart-psi.vercel.app](https://drilling-chart-psi.vercel.app)
2. 브라우저 우측 상단의 **메뉴 버튼(`⋮`)** 또는 하단 탭 메뉴를 터치합니다.
3. **`[앱 설치]`** 또는 **`[홈 화면에 추가]`** 메뉴를 선택합니다.
4. 확인 팝업에서 **`[설치]`**를 선택하면 바탕화면에 설치가 완료됩니다.

---

### 💻 PC / Mac (Chrome 네이티브 앱 설치)
1. Chrome 브라우저에서 ProDrill 접속 주소로 들어갑니다.
2. 주소창 우측 끝의 **`[앱 설치]`** 아이콘(컴퓨터/화살표 모양)을 클릭합니다.
3. 독립 실행형 데스크톱 앱으로 즉시 설치되어 바깥 화면에서 앱처럼 사용하실 수 있습니다.

---

## 🔑 2. 구글 로그인 및 자동 동기화 시작하기

1. 바탕화면에 생성된 **ProDrill 앱 아이콘**을 터치하여 실행합니다.
2. 앱이 처음 켜질 때 화면 중앙에 안내창이 표시됩니다.
3. **`[구글 계정 연결하기]`** 버튼을 누릅니다.
4. 사용하시는 **구글 이메일 계정**을 선택하고 동의하면 **0초 만에 동기화가 활성화**됩니다.
5. 이제 지공 차트를 작성할 때마다 지공사 본인의 구글 드라이브로 백업이 안전하게 보호됩니다.
